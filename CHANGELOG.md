# Changelog — Cosmora Platform

All notable changes to Cosmora will be documented in this file.

## [v1.0.0] - 2026-07-27
### Added
- **Core Platform**: JWT Authentication, Refresh Tokens, RBAC (`Admin`, `Seller`, `Customer`).
- **Timeline Module**: Eras, Timeline Events, Event Media galleries.
- **Solar System Module**: Planets, Moons, Trivia Facts, 3D asset links.
- **Mission Tracking**: Space Agencies, Missions, Milestones, Live Countdown Hub.
- **Story Engine**: Categories, Tags, Stories, Chapters, Reading Progress tracking.
- **Universal Search**: Cross-entity search, autocomplete suggestions, trending queries.
- **Personalization**: Bookmarks, User Collections, Activity tracking.
- **Notifications**: WebSocket real-time feed, push notifications, admin broadcasts, scheduler.
- **AI Space Assistant**: Grounded Retrieval-Augmented Generation (RAG) with citations & streaming.
- **Admin CMS**: Moderation workflows, bulk publishing/archiving, audit logging (`AdminAuditLog`).
- **Analytics Engine**: Event telemetry, DAU/MAU KPIs, CSV and JSON report exports.
- **Performance & Scalability**: Redis caching, background task workers, rate limiting, deep health checks.
- **Production Release Engineering**: Multi-stage Docker, GitHub Actions CI/CD pipelines, Prometheus metrics.
